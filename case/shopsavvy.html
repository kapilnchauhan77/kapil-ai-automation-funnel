ShopSavvy: Voice commerce agents

A voice-first commerce platform with MCP agent coordination and Shopify flows

Client
ShopSavvy
Industry
Conversational commerce
Contribution
Solution architecture and engineering

Context

A shopping conversation can move between product search, recommendations, cart changes, checkout and support. A voice interface also needs to handle interruptions and follow-up questions while retaining the right store context. The system needed to coordinate those capabilities with Shopify catalog and order data.

System and approach

LiveKit handles real-time audio, while MCP services expose commerce capabilities to the agent system. Routing directs requests to specialized search, cart, checkout, support and recommendation agents. React and Shopify integrations connect the conversation to the storefront and its records.

  • Use LiveKit for real-time voice transport.
  • Coordinate MCP services for search, cart, checkout, support, and recommendations.
  • Keep routing separate from specialised agents.
  • Connect Shopify catalog and order flows without mixing commerce state into audio.

Delivered scope

The scope combines real-time voice interaction, agent orchestration and Shopify integration, with separate responsibilities for audio transport and commerce operations.

Technology

  • MCP
  • Python
  • FastAPI
  • React
  • Shopify API
