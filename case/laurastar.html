Laurastar: Connected product assistant

A connected appliance companion with grounded product guidance and BLE pairing

Client
Laurastar
Industry
Connected products and IoT
Contribution
Solution architecture and engineering

Context

An appliance companion needed to connect a physical device to a useful mobile experience. Pairing, usage history and maintenance guidance had to account for the state of the appliance. Product questions also needed answers grounded in Laurastar knowledge, alongside the app's ordinary device controls.

System and approach

A React Native application connects to the appliance over BLE and synchronizes device context with an Azure backend. Usage tracking supports offline activity. An Azure OpenAI assistant combines product knowledge with device context for guidance and maintenance prompts.

  • Build React Native flows for BLE appliance pairing.
  • Synchronise telemetry and contextual device state through Azure.
  • Ground product answers in approved knowledge with brand guardrails.
  • Support offline tracking and contextual maintenance prompts.

Delivered scope

The work combines mobile development, device connectivity, cloud telemetry and an assistant grounded in product information.

Technology

  • React Native
  • BLE
  • Azure
  • Azure OpenAI
  • TypeScript
  • Node.js
